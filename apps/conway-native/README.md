## Changes

The canvas starts as **Default**, with infinite space and Dark theme. Pattern previews follow the mouse and click to place live cells without replacing the canvas or erasing cells in blank pattern gaps. The separate cell cursor starts in the drawing centre and moves with arrow keys; mouse movement does not move it. Saved patterns have the same thumbnail cards as built-ins.

**Specify Chart Size** sits beside the Canvas readout and opens width and height fields (5–512). **Apply** sets a finite canvas; **Infinite** returns to an infinite canvas. Cropping is undoable. Wrap edges connects opposite edges of a finite canvas. Birth at zero requires a finite canvas, because an infinite empty universe would produce infinitely many cells.

Paint and Erase remain editing tools. Pan is a separate outlined button, off by default, filled while enabled. The old canvas fullscreen button is removed. macOS retains its native green fullscreen control and Control–Cmd–F shortcut.

Dark, Light and Sepia themes apply immediately to the entire interface, controls and app dialogs. Light and Sepia use the original Python background and cell palette. Gridlines are green in Dark, black in Light and brown in Sepia. Windows controls have themed text boxes, clearer tool icons and focus/hover states; all boards draw square cells. Other-platform icons use rounded-square artwork. The sidebar shows the app icon, version, author and linked nithi.land.

Save Canvas asks for a name in an app dialog; Load Canvas lists saved canvases. Saving a loaded canvas offers overwrite or a new name. Import and Export use system file dialogs. Closing with unsaved changes offers Save, Discard or Cancel. Recovery autosaves do not count as explicit saves. Android prompts when leaving through Back; OS force-stop/process termination cannot show a save prompt.

Edit Rules opens numeric birth/survival fields with Reset to Classic Conway (B3/S23). A stable canvas displays **Equilibrium reached** while generations continue. Generate uses the requested percentage as a per-cell random probability; on an infinite canvas it fills the visible region.

**Live cells over time** shows a simple line graph above the canvas, without axes or scales. It tracks the latest 2,048 generations, reflects edits to the current generation and follows Undo, Redo, Back and Reset Gen 0. The theme colors apply to the graph too. Named saves and portable JSON retain the v2 `population_history` field; older files without it start from their current live-cell count.

A 17-step first-use tour is tracked in JSON. Help replays it; each step highlights the relevant controls and explains the platform’s Cmd or Ctrl shortcuts. It covers editing, selection, clipboard, patterns, files, borders, rules, themes, playback, undo and zoom.

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| Move cell cursor / extend selection | Arrows / Shift + arrows |
| Make selected cells alive / dead | Enter / Delete or Backspace |
| Invert selection, or toggle cursor cell | Space |
| Unselect and cancel pattern preview | Esc (one tap) |
| Undo / Redo | Cmd–Z / Cmd–Y on Mac; Ctrl–Z / Ctrl–Y elsewhere |
| Copy / paste selection, centred on cell cursor | Cmd–C / Cmd–V on Mac; Ctrl–C / Ctrl–V elsewhere |
| Save / Load Canvas | Cmd–S / Cmd–O on Mac; Ctrl–S / Ctrl–O elsewhere |
| Reset Gen 0 | Cmd–R on Mac; Ctrl–R elsewhere |
| Paint / Erase / Pan | B / E / H |
| Step / Fit / Zoom | . / F / + and − |
| Temporary pan | Option-drag on Mac; Alt-drag elsewhere |

Shift-drag adds cells to the selection. Unselect and Save to Pattern Library are disabled without a selection. Clipboard paste copies live and dead squares; pattern placement adds live squares. Start/Stop remains an explicit control. Duration is seconds between generations (0.1–10).

## Saved data and v2.0

Desktop editions reuse `~/Conway Game of Life Canvases`, the original v2.0 location. They create it only when missing. Named canvases are `.life.json`; named patterns are `.pattern.json`. Existing v2 files are accepted, and the original v2 saved-list validator quietly hides canvases over 100 × 100. Installing v3 does not require moving or replacing that folder.

Files retain the v2 rows, cols, grid, name, generation, generation_zero_grid and rules fields. Additional native fields preserve infinite coordinates and borders. The original v2 validator has been exercised against new compatible files, including generation-zero data.

Portable Import/Export accepts at most 100 × 100. Larger canvases produce a popup asking for a smaller canvas. **Save Canvas** retains the complete larger/infinite canvas locally. Mac also offers exporting a selected region up to 100 × 100. v2 cannot display infinite-world metadata; it sees the finite projection of compatible files.

Android reuses the previous app ID and its Storage Access Framework folder preference. Choose **Data Folder** in the menu to use the same shared folder as v2. Otherwise Android stores named files in its private app folder. Uninstalling an Android app removes private files and its permissions; export or choose a shared folder before uninstalling. Old WebView-local-storage-only charts are not directly accessible to the new native activity.

Recovery/session state stays in each native app’s local data folder. QA uses isolated folders and restores Android instrumentation data backups. No Android network permission is requested.
