## AppImage and DEB distribution — v3.0

`build-packages.sh OUTPUT_DIR` builds the native GTK app on Ubuntu 24.04 for the host x86_64 or ARM64 architecture. Install build-essential, pkg-config, GTK3/JSON-GLib development packages, librsvg2-dev, libgirepository1.0-dev and dpkg-dev first. The official linuxdeploy, GTK plugin, appimagetool and AppImage runtime downloads are checked against recorded SHA-256 hashes. A mismatch stops the build.

The DEB retains package identity `nithi-land-conway-life-lab` and provides the `conway-life-lab` compatibility launcher, so apt upgrades the earlier package without deleting user data. Dependencies are generated by dpkg-shlibdeps. AppImages include GTK libraries/resources, schemas, image loaders, icons, desktop integration, the app MIT license and dependency copyright notices. Their website filenames remain versionless to preserve existing download URLs. DEB filenames carry 3.0.

The packaging workflow verifies the real v2.0→v3.0 DEB upgrade, installed app, extracted AppImage and runtime extraction launch on each architecture, with isolated library/session directories. Screenshots and logs are retained with build artifacts. This packaging does not change the user's existing Linux installation or establish a Flatpak sandbox test. Builds target Ubuntu 24.04; AppImages require compatible Linux with glibc 2.39 or later, and DEBs need matching recent GTK3/JSON-GLib distribution packages.
